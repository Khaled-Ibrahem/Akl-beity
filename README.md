# أكل بيت Daily

Responsive Arabic RTL landing page for Akl Beit Daily. It is a static site with no build step or backend.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Update business details

Edit `data.js` to change the Forms.app form ID and display options, WhatsApp number, service area, social URLs, and FAQ answers. The menu section contains a food image and the Forms.app trigger. The subscription section explains the flexible weekly duration: 2 to 7 days per week. Main calls to action take visitors to the menu section. Set `contact.whatsapp` to an international phone number with digits only (for example, `2010XXXXXXX`) to activate WhatsApp contact links.

Replace the stock food image URLs with approved brand photography when available.
